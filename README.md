# SentinelX
Before astronauts go to the Moon or Mars, teams test their equipment and plans in places on Earth that look and feel similar, like the Atacama Desert or the Arctic. But most teams keep going back to the same few famous spots, and there’s no easy way to tell which place on Earth best matches a particular landing site.

We built SentinelX, a website with an interactive globe that does exactly that. You pick a destination, such as Gale Crater on Mars or a lava-tube pit on the Moon, and it ranks 51 places on Earth by how closely they match, using NASA climate data and the ground conditions at each site. It explains every score, compares each site with the real destination, and can scan any part of the globe for new matches.

It also points out promising places almost nobody has studied yet, like a desert lava tube in Saudi Arabia that beat every well-known site for the Moon
